## Матрица компетенций специалистов по тестированию

Шаблон для оценки и развития QA-команды. С ним можно описать требования к грейдам, оценить сотрудника и найти, что включить в индивидуальный план развития (ИПР). Формулировки знаний и навыков подходят для должностных инструкций.

Требования к знаниям, навыкам и уровням владения зависят от проекта, продукта и команды. Поэтому шаблон — отправная точка: поправьте его под себя.

### Что внутри

| Лист | Содержание |
| --- | --- |
| Инструкция | Как устроен шаблон и как им пользоваться |
| Шкала | Уровни владения от 0 («не требуется») до 5 («экспертный») |
| Ручное | Знания и навыки на каждом уровне для ручного тестирования |
| Автоматизированное | То же для автоматизации тестирования |
| Нагрузочное | То же для нагрузочного тестирования |
| Грейды | Требуемый уровень владения по каждой трудовой функции для каждого грейда |
| Оценка сотрудника | Выбираете грейд, ставите фактические уровни — разрыв и статус считаются сами |

### Треки и грейды

| Трек | Грейды |
| --- | --- |
| Ручное тестирование | Младший специалист / стажёр → Специалист → Старший специалист → Ведущий специалист → Менеджер по тестированию |
| Автоматизация | Младший инженер / стажёр → Инженер → Старший инженер → Ведущий инженер → Менеджер по автоматизации тестирования |
| Нагрузочное тестирование | Младший инженер / стажёр → Инженер → Старший инженер → Ведущий инженер → Менеджер по нагрузочному тестированию |
| Управление | Руководитель тестирования |

### Как пользоваться

1. На листах «Ручное», «Автоматизированное» и «Нагрузочное» поправьте формулировки под свой продукт и стек: инструменты, языки, предметную область.
2. На листе «Грейды» поправьте требуемые уровни (жёлтые ячейки). Колонка «Проверка» подсветит строку, если в треке старший грейд получил уровень ниже младшего.
3. Скопируйте лист «Оценка сотрудника» для каждого человека, выберите грейд в ячейке C4 и проставьте фактические уровни в колонке F.
4. Статусы: «Соответствует», «Зона роста» (ниже требуемого на 1), «Приоритет ИПР» (ниже на 2 и больше), «Не требуется».
5. Функции со статусом «Приоритет ИПР» — первые кандидаты в ИПР. Что именно нужно освоить, смотрите на листе матрицы трека в колонке нужного уровня.

Уровни накопительные: каждый следующий включает всё, что требуется на предыдущих, поэтому на уровне указано только то, что добавляется.

### Основа

- Профессиональный стандарт 06.004 «Специалист по тестированию в области информационных технологий» (приказ Минтруда России от 02.08.2021 № 531н). У каждого знания и навыка указан код трудовой функции, например `C/01.6`.
- Блок E «Управление проектом и командой проекта» — по профстандарту 06.016 «Руководитель проектов в области информационных технологий» (приказ Минтруда России от 18.11.2014 № 893н). Перед использованием проверьте актуальную редакцию.
- Пометка «доп.» — знания, которых нет в профстандарте: предметная область, конкретные виды тестирования.

Файл работает в Microsoft Excel, LibreOffice Calc и Google Таблицах. В Google Таблицах выпадающий список грейдов на листе «Оценка сотрудника» может потеряться при загрузке. Тогда добавьте его заново: «Данные» → «Настроить проверку данных» → «Раскрывающийся список (из диапазона)» → `Грейды!D6:S6`.
